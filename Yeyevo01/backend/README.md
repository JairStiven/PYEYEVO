
# Backend para Carrito de Compras

Este es un backend básico para manejar los datos de la base de datos `yeyevo`. Está desarrollado con Node.js y usa Express para servir los datos.

## Pasos para correr el servidor

1. Asegúrate de tener Node.js instalado.
2. Instala las dependencias ejecutando:

   ```bash
   npm install express mysql2 cors
   ```

3. Ejecuta el servidor:

   ```bash
   node server.js
   ```

4. El servidor estará disponible en `http://localhost:5000`.
